# AuditTimeline – Mendix Pluggable Widget

## Overview

**AuditTimeline** is a customizable Audit Timeline and Audit History Grid widget for Mendix applications. It provides a clear, interactive way to view record changes, user activities, and historical data.

The widget helps users track and review changes made to application records through a visual timeline or a structured grid view, making audit information easier to understand, monitor, and analyze.

## Features

* **Timeline View** – Display audit records chronologically with expandable and collapsible details.
* **Grid View** – View audit history in a structured table with eight columns: Date & Time, Object, User, Action, Attribute, Old Value, New Value, and Description.
* **Global Search** – Search audit records across relevant fields.
* **Individual Column Filters** – Filter records independently by date, object, user, action, attribute, old value, new value, and description.
* **Action Filter** – Filter records by action type.
* **User Filter** – View audit records for a specific user.
* **Date Range Filter** – Filter records using start and end dates.
* **Column Sorting** – Sort supported columns in ascending or descending order.
* **Pagination** – Navigate through records with configurable page sizes of 10, 20, 50, or 100 rows.
* **Clear Filters** – Reset active filters and return to the first page.
* **Excel Export** – Export filtered audit records to `.xlsx` format for reporting and analysis.
* **Responsive Layout** – Support wide tables with horizontal scrolling and responsive styling for smaller screens.


## Use Cases

* Track changes to business records.
* Review user activities and modification history.
* Monitor historical data in enterprise applications.
* Improve audit visibility and traceability.

## Technology Stack

* Mendix Pluggable Widgets
* React
* TypeScript
* CSS
* SheetJS (xlsx) for Excel export

## Filtering and Export

* The widget supports combined filtering through global search, action and user selection, date ranges, and individual column filters.
* Excel export includes the records matching the active filters, allowing users to generate focused audit reports.

## Compatibility

* Developed for Mendix applications using the Pluggable Widget framework.
* 11.12.3 or Higher
* Web Applications
